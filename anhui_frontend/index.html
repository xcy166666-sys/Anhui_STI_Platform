Agent 流程

  • IntentAgent识别用户是闲聊、需求补充还是项目推荐。
  • MemoryAgent抽取短期会话记忆，复用需求单结构化字段。
  • RetrievalAgent调用 pgvector 项目库做 RAG 语义召回。
  • MatchingAgent按赛道、阶段、合作方式等字段做规则匹配。
  • RecommendationAgent融合 RAG 分数和传统匹配分数排序。
  • EvidenceAgent整理推荐依据和项目字段证据。
  • ResponseAgent用 qwen-plus 生成面向用户的对话回复。
